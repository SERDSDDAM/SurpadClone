# توثيق تطوير الهيكل الجغرافي اليمني
## نظام "بنّاء اليمن" - متصفح البيانات الجغرافية الشامل

---

## 📋 نظرة عامة

تم تطوير نظام شامل لإدارة واستعراض البيانات الجغرافية للجمهورية اليمنية يدعم **التسعة مستويات الإدارية** بدءاً من المحافظات وصولاً إلى الشوارع. النظام مصمم بواجهة عربية احترافية تدعم التخطيط من اليمين إلى اليسار (RTL) ويوفر تجربة مستخدم متقدمة للبحث والتصفح الهرمي.

---

## 🏗️ الهيكل الإداري التسعة مستويات

### المستويات الإدارية المدعومة:

| المستوى | الاسم العربي | الاسم الإنجليزي | الرمز | الوصف |
|---------|-------------|-----------------|------|--------|
| 1 | المحافظات | Governorates | `governorates` | الوحدة الإدارية الأساسية في الجمهورية اليمنية |
| 2 | المديريات | Districts | `districts` | الوحدة الإدارية التابعة للمحافظة |
| 3 | العزل | Sub-Districts | `subDistricts` | الوحدة الإدارية التابعة للمديرية |
| 4 | الأحياء | Neighborhoods | `neighborhoods` | الوحدة الإدارية التابعة للعزلة |
| 5 | القطاعات | Sectors | `sectors` | الوحدة الإدارية التابعة للحي |
| 6 | الكتل الإدارية | Administrative Blocks | `administrativeBlocks` | الوحدة الإدارية التابعة للقطاع |
| 7 | وحدات الأحياء | Neighborhood Units | `neighborhoodUnits` | الوحدة الإدارية التابعة للكتلة الإدارية |
| 8 | كتل الوحدات | Unit Blocks | `unitBlocks` | الوحدة الإدارية التابعة لوحدة الحي |
| 9 | الشوارع | Streets | `streets` | الشوارع والطرق العامة |

## 🔍 نظام البحث المتقدم

### أوضاع البحث الثلاثة:

#### 1. البحث البسيط (Simple Search)
- بحث نصي مباشر
- مطابقة جزئية في الأسماء
- نتائج فورية

#### 2. البحث التفاعلي (Autocomplete Search)
- اقتراحات أثناء الكتابة
- عرض المعلومات الإضافية
- المسار الهرمي للعناصر
- تجميع النتائج بالفئات

#### 3. البحث المتقدم (Advanced Search)
خيارات تحكم شاملة:

| الخيار | القيم المتاحة | الوصف |
|--------|-------------|--------|
| **نطاق البحث** | أسماء فقط، أكواد فقط، الكل | تحديد نوع البيانات المراد البحث بها |
| **نوع المطابقة** | جزئية، تامة | نوع مطابقة النص المدخل |
| **ترتيب النتائج** | الاسم، الكود، الصلة | معيار ترتيب النتائج |
| **اتجاه الترتيب** | تصاعدي، تنازلي | اتجاه عرض النتائج |

### React Query Integration:
- **Caching**: تخزين مؤقت ذكي للبيانات
- **Stale Time**: 5 دقائق قبل إعادة الجلب
- **Background Updates**: تحديث خلفي للبيانات
- **Error Handling**: معالجة شاملة للأخطاء

### معاملات الاستعلام المدعومة:
```typescript
interface QueryParams {
  search?: string;           // نص البحث
  searchIn?: 'name' | 'code' | 'all';  // نطاق البحث
  exactMatch?: boolean;      // نوع المطابقة
  includeGeometry?: boolean; // تضمين الهندسة
  parentId?: string;         // المعرف الأب
  sortBy?: 'name' | 'code' | 'relevance'; // ترتيب
  sortOrder?: 'asc' | 'desc'; // اتجاه الترتيب
  limit?: number;            // حد النتائج
  offset?: number;           // الإزاحة
}
```
